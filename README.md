# AETHER ENGINE
A custom-made, data-driven 2D game engine framework for developing your own 2D games.

# About
This was a project I made for my final year project for University. It was made using OpenGL and external librires. It is meant to be used as a tool to making
your own 2D games or as template to help you make your own custom engine. I intend on continuing to improve it since there's a lot that can be done to make it 
better, especially as I continue to learn more about OpenGL or graphics programming as a whole.

# Developed Using
Visual Studio 2022, ISO C++ 17 Standard, ISO C17 Standard

# External Librarires Used
1. OpenGL
2. Simple Fast Multimedia Library (SFML)
3. ImGui
4. glm
5. GLFW/GLEW

# GUIDE TO DIRECTORIES
This folders/files must be stored in your x64 Debug/Release in order for it to work. For any changes made, it must also be applied in the code e.g. changing 
a folder name/ location. The same applies for any new additions. 
Tip: All files are intialized in Game.cpp, so you will find path definitions there.
# Audio
1. assets/audio/music/ - store all in game music
2. assets/audio/sfx/ - stores all in game sound effects

# Data
1. assets/data/ - store all json files
2. assets/data/textures/items - store all item textures

# Images
1. assets/images/ - store splash screen image
